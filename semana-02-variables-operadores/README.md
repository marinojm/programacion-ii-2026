## Descripción de la actividad
Programa de consola en Java desarrollado en IntelliJ IDEA que solicita al usuario sus datos personales y año de nacimiento para realizar el cálculo de su edad aproximada en años y meses, determinando además si es mayor de edad mediante un operador de comparación booleano sin el uso de condicionales.

## Datos solicitados
* Nombre completo
* Carné
* Año de nacimiento
* Año actual

## Cálculos realizados
* **Edad aproximada:** `anioActual - anioNacimiento`
* **Edad en meses:** `edadAproximada * 12`
* **Mayoría de edad:** `edadAproximada >= 18`

## Instrucciones de ejecución
1. Clonar o descargar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Navegar a `src/CalculadoraEdad.java`.
4. Ejecutar la clase principal (`Run 'CalculadoraEdad.main()'`).
