# Control de Compras del Hogar

## Descripción
Aplicación de consola desarrollada en Java para registrar y analizar las compras realizadas en un hogar durante una semana. El proyecto aplica Programación Orientada a Objetos (POO), estructuras de control y la gestión diferenciada de colecciones en Java.

## Colecciones Utilizadas
* **`ArrayList<Producto>`**: Almacena de forma ordenada todos los productos registrados.
* **`HashSet<String>`**: Mantiene el listado de categorías únicas sin duplicados.
* **`HashMap<String, Double>`**: Asocia cada categoría con el total acumulado de dinero gastado.

## Requisitos de Ejecución
1. JDK 11 o superior instalado.
2. Un IDE de Java como IntelliJ IDEA o ejecución directa vía terminal.

## Instrucciones para Ejecutar
1. Clonar el repositorio.
2. Navegar a la carpeta `src/`.
3. Compilar y ejecutar la clase `MainControlCompras.java`.
4. Ingresar 5 productos válidos para generar el resumen final y realizar consultas dinámicas.
