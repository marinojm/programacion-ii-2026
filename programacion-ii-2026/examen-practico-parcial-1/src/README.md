## Descripción del programa
Programa desarrollado en Java que simula las operaciones básicas de un cajero automático para una sola cuenta bancaria. Permite el control de acceso mediante PIN, consulta de saldo, depósitos validados, retiros normales y retiros con comisión mediante overloading, conservando contadores y el saldo actualizado durante toda la sesión.

## Ejecución del programa
1. Abrir el proyecto en IntelliJ IDEA.
2. Asegurarse de tener configurado JDK 17 o superior.
3. Ubicar y ejecutar el archivo principal `CajeroAutomatico.java` haciendo clic derecho en la clase y seleccionando **Run 'CajeroAutomatico.main()'**.
