# Cálculo de Área de Figuras Geométricas

## Descripción
Aplicación de consola desarrollada en Java utilizando Programación Orientada a Objetos (POO). El programa calcula el área de distintas figuras geométricas aplicando abstracción, encapsulamiento, herencia, sobrescritura y polimorfismo mediante una clase base abstracta y un arreglo polimórfico.

## Figuras Implementadas
* Círculo
* Rectángulo
* Triángulo

## Instrucciones para Ejecutar
1. Abrir el proyecto en IntelliJ IDEA.
2. Navegar a la carpeta `src/`.
3. Abrir y ejecutar el archivo `Main.java`.
4. Los resultados de cada figura se mostrarán en la consola formatados con dos posiciones decimales.
